TEMEL KAVRAM

CDN Nedir?

CDN, Content Delivery Network ifadesinin kısaltmasıdır. Türkçede İçerik Dağıtım Ağı anlamına gelir.

🌐

İçerik Dağıtım Ağı

CDN, web sitesi içeriklerinin farklı coğrafi bölgelerde bulunan sunucular üzerinden kullanıcılara ulaştırılmasını sağlayan dağıtık bir ağ sistemidir.

Böylece içerikler kullanıcıya daha yakın noktalardan sunulabilir. Bu durum gecikmeyi azaltmaya ve ana sunucunun yükünü hafifletmeye yardımcı olur.

⚡

Daha hızlı erişim

Önbelleğe alınmış içerikler uygun durumlarda kullanıcıya yakın sunuculardan iletilir.

🌍

Dağıtık sunucular

İçerikler farklı bölgelerde bulunan CDN noktalarından sunulabilir.

📦

Önbellekleme

Uygun içerikler geçici olarak saklanarak tekrar tekrar kaynak sunucuya gitme ihtiyacı azaltılabilir.

SİSTEMİN ÇALIŞMASI

CDN Nasıl Çalışır?

Kullanıcı bir web sitesine erişmek istediğinde istek CDN ağı üzerinden yönlendirilebilir.

01
👤

Kullanıcı

Web sitesine bir istek gönderir.

→
02
🌐

CDN noktası

→
03
🖥️

Kaynak sunucu

Gerekli olduğunda içerik kaynak sunucudan alınır.

Not: Her istekte kaynak sunucuya gidilmez. Uygun ve önbellekte bulunan içerikler doğrudan CDN üzerinden sunulabilir.

ÖNBELLEK SİSTEMİ

Cache HIT ve Cache MISS

CDN önbelleğinin çalışma durumunu HTTP yanıt başlıkları üzerinden inceleyebiliriz.

CACHE HIT

İçerik bulundu

İstenen içerik önbellekte bulunduğunda CDN içeriği önbellekten sunabilir.

Örnek: HIT
CACHE MISS

İçerik bulunamadı

İstenen içerik önbellekte yoksa CDN, uygun durumda kaynak sunucuya başvurur.

Örnek: MISS
HTTP Yanıt Başlığı 
Cache-Control: public, max-age=3600
CF-Cache-Status: HIT

CF-Cache-Status başlığı, Cloudflare'ın önbellek davranışını incelememizi sağlar.

UYGULAMALI PROJE

Cloudflare Pages ile Statik Site

Bu web sitesi GitHub ve Cloudflare Pages bağlantısı kullanılarak yayınlanmaktadır.

01

GitHub Repository

HTML, CSS ve diğer proje dosyaları GitHub deposunda saklanır.

02

Cloudflare Pages

GitHub deposu Cloudflare Pages'e bağlanır. Değişiklikler otomatik dağıtılabilir.

03

Pull Request Preview

Yeni bir branch üzerinden PR açıldığında ayrı bir önizleme ortamı oluşturulur.

04

Main Production

Değişiklikler main dalına birleştirildiğinde canlı site yeni sürümle güncellenir.

_headers dosyası ne işe yarar?

Cloudflare Pages üzerinde statik dosyaların HTTP yanıt başlıklarını belirlemek için _headers dosyası kullanılabilir. 

/
  Cache-Control: public, max-age=0, must-revalidate

/style.css
  Cache-Control: public, max-age=3600
